## 一、 核心科研结论摘要 (Executive Summary)

本研究对 TimesFM-3.0 的跨通道注意力机制（Cross-Channel Attention）进行了系统性的因果探针（Causal Probing）与结构闭环验证，得出四大具有里程碑意义的科学结论：

1. **多变量收益的本质是强结构信号（E1 发现）**：
   - 跨通道注意力并非普遍生效，但在具有**密集物理耦合**的数据集上展现出极高的、统计学上极显著的性能增益：
     - **Weather ($H=96$)**: 收益达 **$+8.04\%$** ($p_{\text{adj}} = 5.43\times 10^{-10}$)；
     - **ETTh2 ($H=336$)**: 收益达 **$+7.20\%$** ($p_{\text{adj}} = 1.34\times 10^{-4}$)；
     - **Electricity ($H=96$)**: 收益达 **$+2.60\%$** ($p_{\text{adj}} = 8.46\times 10^{-20}$)。
   - 然而在**相位未对齐**的周期信号上出现严重的**负迁移（Negative Transfer）**：
     - **Solar**: 单变量表现显著优于多变量，随预测跨度拉长误差急剧扩大（$H=96: B=-7.72\% \to H=720: B=-31.95\%$, $p_{\text{adj}} = 1.12\times 10^{-12}$）。这证实了“未对齐的昼夜周期等价于引入结构性噪声”的核心假设。

2. **跨通道注意力真正“在读什么”（E2 发现）**：
   - **通道置换不变性 ($N1$)**：在所有 8 个数据集上 $|\Delta\text{MSE}| \le 9.54\times 10^{-7} < 10^{-6}$，完全证实模型满足通道可交换性。
   - **时间对齐与相位破坏 ($I2$ vs $I3$)**：
     - 在 Electricity 上，非日历对齐替换 ($I2$) 的破坏度 $R = 2.065$ ($p_{\text{adj}} = 2.01\times 10^{-6}$)；
     - 严格日历对齐替换 ($I3$) 的破坏度降为 $R = 0.505$ ($p_{\text{adj}} = 0.350$)。
     - **$R(I2) \gg R(I3)$ 证明：模型跨通道注意力极度依赖不同通道间同步的日/周季节性相位，而非仅仅利用通道边缘均值**。
   - **正对照极强响应 ($P1$)**：当注入包含目标未来信息的领先指标时，预测误差瞬间下降达 **$-48.97\%$** ($p_{\text{adj}} < 10^{-11}$)，确证探针机制对有效跨通道信息具有灵敏的因果响应。

3. **通道预算 $K$ 的最佳 Pareto 折中前沿（E5 发现）**：
   - **$K=16 \sim 32$ 是最佳甜蜜点**：在 Electricity 上，$K=32$ 达到最低 MSE `0.1260`（时延仅 52.9ms）。盲目扩大到 $K=128$ 时延激增 +260%（达 158.9ms），但 MSE 反弹至 `0.1271`。
   - **无对齐数据的“通道诅咒”**：在 Solar 上，随通道数 $K$ 增加，MSE 从 `0.2162` ($K=1$) 单调剧烈恶化至 `0.2970` ($K=128$)，证实盲目堆叠通道会加速性能崩溃。

4. **理论可达边界与 Kalman 闭环（E3 发现）**：
   - 在严格可控的低秩 ($G1$)、局部块 ($G2$)、领先滞后 ($G5$) 合成数据中，验证了所有配置均满足 $MV^* \le UV^*$，且零样本 TimesFM-3 在未微调情况下不会违反物理上界。
